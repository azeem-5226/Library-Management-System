# Library Management System

A simple Library Management System built using HTML, CSS, JavaScript, PHP, and MySQL.

## Features
- Add new books
- Issue books to students
- Return books
- View available books
- Track issued books

## Technologies Used
HTML, CSS, JavaScript, PHP, MySQL

## Database
Library_database

## Run the Project
1. Copy project folder to `xampp/htdocs/`
2. Start Apache and MySQL in XAMPP
3. Create database **Library_database**
4. Open in browser:  
http://localhost/Library-Management-System
